# Mastershot Studio 网站工作总结

更新日期：2026-10-19

## 项目定位

这是一个面向电影、剧集、TVC 与后期合作方的个人工作室作品网站。整体目标不是普通个人简介，而是在约 30 秒内让合作方看清：李嘉伟是谁、做过什么、负责什么、作品质感如何，以及如何直接联系。

视觉方向参考了 Blur、Exile Edit、Digital Domain、ILM、Wētā FX、DNEG 等电影与视效工作室的作品展示逻辑，并结合本项目的中文内容和中国大陆访问环境做了本地化处理。

## 已完成的页面与视觉系统

- 首页包含约 1.5 秒的 MASTERSHOT 开场字标，并通过整页上滑进入主界面。
- 主界面采用黑、白与橘黄色强调色，使用 Helvetica / Apple-like system sans 风格，保留较宽字距和页边留白。
- 大字标支持局部字母的海报纹理显现与轻微放大，不改变字标尺寸和外轮廓。
- 右上角使用提供的白色 Mastershot 标志；导航、返回和关闭控制保持醒目但不过重。
- 主要作品区域采用四等分海报网格，统一可视比例和对齐方式，避免人物头部被裁掉。
- 作品详情页采用“预告片 → 项目信息 → 简介 → 海报 / 剧照墙”的浏览顺序，海报在同一页继续滚动查看。
- 联系区包含电话、邮箱、微信添加入口和微信二维码，并明确表达合作邀约。
- 页面说明中保留版权、制作周期和待播项目暂时无法完整展示的说明，待项目可公开后再更新。

## 播放与作品交互

`script.js` 负责项目详情、预告片弹层和 Bilibili 播放器的交互：

- Bilibili 视频统一转为 `player.bilibili.com/player.html` 嵌入地址。
- 忽略用户原链接中的 `t=` 时间点，并追加 `t=0`、`start_progress=0`、`time=0`，每次从第一帧开始。
- 追加 `high_quality=1`、`quality=112`、`qn=112` 和 `fourk=1`，向平台请求最高可用清晰度。
- 详情页和播放弹层均有右上角 X；退出、返回首页或切换项目时会停止并移除 iframe，避免声音继续播放。
- iframe 初始化期间保留当前海报作为背景，不让用户先看到黑屏；加载超时后仍会安全解除 loading 状态。
- 支持项目内播放，不强制跳出到 YouTube 或外部网站；如平台不提供可用嵌入，则保留可访问的外链字段。
- 预告片弹层尺寸保持在参考稿的适中范围，不默认全屏。

## 已知限制

1. Bilibili 是否真正输出 1080P 由片源、账号权限、地区、浏览器和平台自适应策略共同决定。页面会请求最高可用质量，但不能在前端强制生成不存在的 1080P。
2. 第三方 iframe 不一定提供可靠的跨域播放结束事件，因此结束后回到浏览区的逻辑采取尽力监听，失败时不阻塞继续浏览。
3. 使用 `file://` 直接双击打开时，浏览器可能限制 iframe、跨域请求或媒体加载；请用本地 HTTP 服务器预览。

## 本地运行

在项目目录运行：

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080>。修改项目资料时优先编辑 `content.js`；修改结构、样式和交互后分别检查 `index.html`、CSS 文件和 `script.js`。

## 维护检查

```bash
node --check script.js
node --check content.js
```

新增作品时，保持海报路径真实存在、预告片链接使用可访问的嵌入来源，并为详情页准备至少一张完整海报作为播放器加载时的视觉兜底。
